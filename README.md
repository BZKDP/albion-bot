# Albion vision bot

Прототип автоматизации игрового интерфейса: захват экрана, поиск шаблонов OpenCV, конечный автомат действий и дополнительный Vision-детектор. По умолчанию пример конфигурации включает `dry_run`: действия мыши и клавиатуры отключены.

## Запуск

```sh
python -m venv .venv
pip install -r requirements.txt
cp config.example.json config.json
cp .env.example .env
python bot.py
```

Перед запуском настроить область экрана и создать шаблоны через `capture_template.py`. Vision-детектор и планировщик требуют собственного API-ключа; локальное распознавание работает без него. Логи, личная конфигурация и записи экрана исключены из Git.
